Lecture 3: **IDE** Setup for Coding

## Quick Compiler (Online Option)

What: A web-based tool to write and execute code instantly without downloading any software.

Why: Good for very quick testing or absolute beginners who just want to see code run. (Example used: CodeHelp Quick Compiler).

Limitations: Not ideal for managing multiple files or large projects.

## IntelliJ IDEA (Professional Setup)

What: A popular, industry-standard **IDE** (Integrated Development Environment) for Java development.

Why: Provides advanced tools for organizing files, debugging, and writing complex, multi-file code.

## IntelliJ Project Setup Steps

Download IntelliJ **IDEA** Community Edition (Mac/Windows).

Install and Open.

Click New Project and name it (e.g., *Java **DSA** Series*).

Ensure a **JDK** (Java Development Kit) is selected (IntelliJ will download it automatically if not present).

Let IntelliJ build the project structure.

## Basic IDE Navigation

src (Source) Folder: Where you will store all your .java files.

Creating a new file: Right-click src → New → Java Class → Name it (e.g., Main.java or Maggi.java).

Running Code: Click the green *Play/Run* arrow next to the main method in the code editor.

Terminal/Console: The bottom panel where the output (or errors) of your program will be displayed.
