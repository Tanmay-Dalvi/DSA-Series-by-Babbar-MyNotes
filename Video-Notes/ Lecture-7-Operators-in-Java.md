Lecture 7: Operators in Java  
## What is an Operator?  
What: A special symbol used to perform specific operations on values or variables (e.g., +, -, *).  

Why: To manipulate data, perform math calculations, evaluate conditions, and compare values in code.  

## Arithmetic Operators  
What: Used for basic mathematical operations.  

Types:  

- (Addition)  

- (Subtraction)  

- (Multiplication)  

/ (Division) - Note: Dividing two integers (e.g., 25 / 7) drops the decimal and returns an integer (3).  

% (Modulus) - Returns the remainder of a division (e.g., 25 % 7 = 4).  

## Relational Operators  
What: Used to compare two values. They always return a boolean (true or false).  

Types:  

== (Equal to)  

!= (Not equal to)  

> (Greater than)  

< (Less than)  

>= (Greater than or equal to)  

<= (Less than or equal to)  

## Logical Operators  
What: Used to combine multiple conditions. They operate on boolean values.  

Types:  

&& (Logical **AND**): Returns true **ONLY** if both conditions are true.  

|| (Logical OR): Returns true if at least one condition is true.  

! (Logical **NOT**): Reverses the boolean value (turns true to false, and false to true).  

## Assignment Operators  
What: Used to assign values to variables.  

Shorthand Notations:  

= : Assigns right value to left variable.  

+= : (e.g., a += 5 means a = a + 5)  

-= : (e.g., a -= 5 means a = a - 5)  

*= : (e.g., a *= 5 means a = a * 5)  

/= : (e.g., a /= 5 means a = a / 5)  

%= : (e.g., a %= 5 means a = a % 5)  

## Unary Operators (Increment/Decrement)  
What: Operators applied to a single variable to increase or decrease its value by 1.  

Pre-increment (++a):  

Rule: First increment the value, then utilize the new value in the expression.  

Post-increment (a++):  

Rule: First utilize the current value in the expression, then increment the value in memory.  

Pre-decrement (--a) & Post-decrement (a--): Follows the exact same logic as above, but decreases by 1.
